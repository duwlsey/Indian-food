# 인도 음식 탐정
교사가 화면을 보여 주며 진행하는 인도 음식 사진 퀴즈입니다. 설치나 빌드 없이 실행됩니다.

- 1단계: 전체 사진
- 2단계: 클릭 / Space / 오른쪽 화살표마다 24개 가림막이 하나씩 사라짐. 정답 보기로 즉시 공개 가능.
- 3단계: 사진이 약 0.43초 동안 가로질러 화면 밖으로 사라짐. 다시 보기 지원.
- 각 단계 12문제. 새로 시작할 때마다 섞으며, 직전 진행의 같은 순번에 같은 음식이 나오지 않음.
- 화면 또는 정답 버튼 클릭: 문제 → 정답 → 다음 문제
- Space / 오른쪽 화살표: 앞으로, 왼쪽 화살표: 이전 문제
- 전체 화면 버튼 지원, 음성·채점·입력 없음
- 정답은 원래 음식 이름의 한글 발음과 로마자 표기
- 움직임 줄이기 설정에서는 사진 통과 시간을 0.95초로 완화

`index.html`을 브라우저에서 열면 로컬에서도 사용할 수 있습니다. 사진은 기존 foodie_App의 인도 음식 사진을 사용합니다.
Pretendard 글꼴은 SIL Open Font License로 배포되며 `fonts/OFL.txt`에 라이선스가 있습니다.
