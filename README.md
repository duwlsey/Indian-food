# 인도 음식 탐정
교사가 화면을 보여 주며 진행하는 인도 음식 사진 퀴즈입니다. 설치나 빌드 없이 실행됩니다.

- 1단계: 전체 사진
- 2단계: 24개 가림막이 하나씩 사라짐
- 3단계: 빠르게 이동하는 사진
- 각 단계 12문제, 매번 무작위 순서
- 화면 또는 정답 버튼 클릭: 문제 → 정답 → 다음 문제
- Space / 오른쪽 화살표: 앞으로, 왼쪽 화살표: 이전 문제
- 전체 화면 버튼 지원, 음성·채점·입력 없음

`index.html`을 브라우저에서 열면 로컬에서도 사용할 수 있습니다. 사진은 기존 foodie_App의 인도 음식 사진을 사용합니다.
